## Selected work

### Agentic HR automation

Contributed to a stealth HR automation project at Geekinate covering recruitment and employee operations. The work connects AI-assisted workflows with full-stack product delivery and human approval checkpoints for operational decisions.

### PashtoGPT — low-resource language AI research

[Research repository](https://github.com/Waqar-ahmedkhan/Pashto_GPT)

An open-source toolkit for adapting language models to Pashto, including source auditing, Unicode-safe data preparation, Qwen3-1.7B QLoRA experiments, and Kaggle training workflows. Evaluation work includes held-out benchmarks, native-speaker review, and retrieval and verifier diagnostics. This remains research-stage work; trained weights and measured quality gains have not been released.

### EduAI — personalized learning platform

[Platform repository](https://github.com/Waqar-ahmedkhan/Education-AI-Personalized-Learning-Marketplace) · [Recommendation model](https://github.com/Waqar-ahmedkhan/recommender_model_for_EduAI)

An AI-powered learning platform for students in Pakistan, with course creation, adaptive quizzes, role-based access, summarization, and question answering. The recommendation model uses learner progress and course similarity to support relevant content suggestions.

### Bondvia — real-time video communication

Scaled random video calling to 10K daily users by improving database indexing, API performance, matching reliability, crash resistance, and call-session handling using Node.js, WebRTC, PostgreSQL, MongoDB, and Prisma.

### Space Manager — coworking SaaS

[Live application](https://spacemanager.vercel.app/)

Built serverless workflows for spaces, bookings, customers, dashboards, reports, and administration, connecting responsive interfaces with backend integrations.
